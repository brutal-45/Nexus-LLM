================================================================================
                          🚀 QUICK START GUIDE
================================================================================

1. SETUP VIRTUAL ENVIRONMENT:
   cd Nexus-LLM
   python3 -m venv venv
   source venv/bin/activate  # Linux/Mac
   # venv\Scripts\activate   # Windows

2. INSTALL DEPENDENCIES:
   pip install --upgrade pip setuptools wheel
   pip install -e ".[dev]"

3. VERIFY INSTALLATION:
   bash verify_installation.sh
   # or run manually:
   python -m ruff check nexus_llm/
   python -m black --check nexus_llm/
   python -m pytest tests/test_cli.py tests/test_main.py -v

4. START USING NEXUS-LLM:
   nexus-llm info              # Show system information
   nexus-llm models            # List available models
   nexus-llm chat              # Start interactive chat
   nexus-llm serve             # Start API server on port 8000

5. EXAMPLE USAGE:
   # Chat with default model
   nexus-llm chat

   # Chat with specific model
   nexus-llm chat --model phi-2

   # Start API server
   nexus-llm serve --host 0.0.0.0 --port 8000

   # List recommended models
   nexus-llm models --recommended

   # Download a model
   nexus-llm download gpt2-medium

   # Show system info
   nexus-llm info
